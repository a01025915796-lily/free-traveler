## 1. 설계 원칙

1. **사진이 이끌고 글이 결정을 돕는다.** 여행지 Section은 사진 Card로 시선을 모으고, 상세 Drawer는 일정·예산·교통·안전처럼 결정에 필요한 정보를 순서대로 보여 준다.
2. **코랄은 행동 하나에만 쓴다.** 화면마다 주요 CTA, 선택된 Chip, 즐겨찾기 상태에만 코랄을 쓰고, 상태·경고·오류에는 쓰지 않는다.
3. **안전정보는 색이 아니라 문장으로 읽힌다.** 경보 단계, stale, 오류는 항상 아이콘과 텍스트 라벨을 함께 표시한다.
4. **비어 보이는 화면을 만들지 않는다.** 데이터가 없을 때도 이유, 이용 방법, 다음 행동을 함께 보여 준다.
5. **외부 이동은 이동이라고 말한다.** 항공·숙소 화면은 검색 결과나 가격을 흉내 내지 않고, 요약 확인 후 새 탭으로 이동한다는 사실을 버튼과 문장에 드러낸다.

### 3.2 Semantic 색

코랄(색상각 약 9°)과 겹치지 않도록 오류는 크림슨(343°), 경고는 앰버(39°)로 둔다.

| 의미 | 텍스트·아이콘 | 배경 | 테두리 | 배경 위 대비 | 사용처 |
|---|---|---|---|---:|---|
| `danger` | `#A50E3A` | `#FFF0F3` | `#F4B6C4` | 7.0:1 | 폼 오류, 중대 여행경보(출국권고·여행금지·특별여행주의보), 외부 연결 실패, 삭제 확인 |
| `warning` | `#7A5200` | `#FFF8E1` | `#F1D27C` | 6.5:1 | 안전정보 stale, 여행자제 단계, 승인자가 있는 글의 일정 변경 경고 |
| `info` (safety) | `#175CD3` | `#EFF8FF` | `#B2DDFF` | 5.6:1 | 입력값 비전달 고지, 공식 판단 비대체 고지, 여행유의 단계, 안전 안내 |
| `success` | `#067647` | `#ECFDF3` | `#ABEFC6` | 5.4:1 | 모집중, 승인됨, 저장 완료, 성인 확인 완료 |
| `neutral` | `#3F3F3F` | `#F2F2F2` | `#DDDDDD` | 9.0:1 | 마감, 거절됨, 기각, 대기 |

규칙:
- semantic 색은 항상 아이콘(경고 삼각형, 정보 원, 체크 등)과 텍스트 라벨을 함께 쓴다.
- 여행경보 단계는 외교부 단계명을 그대로 텍스트로 쓴다. 색은 보조 신호다.
- 코랄은 semantic 의미로 쓰지 않는다. 오류 메시지를 코랄로 쓰지 않는다.

### 3.5 레이아웃 기준

| 항목 | Desktop 1440px | Mobile 390px |
|---|---|---|
| 콘텐츠 최대 폭 | 1240px (좌우 여백 100px) | 350px (좌우 여백 20px) |
| 그리드 | 12열, 거터 24px | 4열, 거터 16px |
| Header 높이 | 72px, 상단 고정 | 64px, 상단 고정 |
| Card 열 수 | 사진 Card 3열, 텍스트 Card 3~4열 | 모든 Card 1열 |
| Drawer | 오른쪽 640px, 전체 높이 | 전체 화면 Sheet (상단 모서리 14px) |
| Hero 높이 | 콘텐츠 영역 최대 520px. 1440×900 화면에서 Header 72px + Hero 520px = 592px이므로 다음 Section 제목이 첫 화면에 보인다 | 내용 높이만큼 (검색창 → 사진 순) |

| 구간 | 폭 | 변화 |
|---|---|---|
| Mobile | 768px 미만 | Header 메뉴는 Sheet로, Card 1열, 분할 레이아웃은 위아래로 쌓음, 상세 패널은 Drawer |
| Tablet | 768~1279px | 사진 Card 2열, 분할 레이아웃 유지(6:6), Drawer 폭 560px |

320px 폭에서도 가로 스크롤이 생기지 않아야 한다. 고정 폭 요소는 `min(100%, …)`로 줄어든다.

### 3.6 접근성 기준

| 항목 | 기준 |
|---|---|
| 포커스 | 모든 상호작용 요소에 `:focus-visible` 시 2px `ink` 외곽선 + 2px 간격. 사진 위 요소는 흰색 2px 안쪽 링을 추가한다. 코랄은 포커스 표시에 쓰지 않는다. |
| 터치 영역 | 버튼·Chip·탭·아이콘 버튼·체크박스 행 모두 최소 44×44px. 주요 버튼 높이 48px, 입력 높이 48px. |
| 키보드 | Tab 순서는 화면 순서와 같다. Drawer·Modal은 열릴 때 제목으로 포커스 이동, 포커스 가두기, Esc로 닫기, 닫으면 연 요소로 포커스 복귀. 탭은 좌우 방향키로 이동. |
| 스크린리더 | Section마다 `h2`, 폼 오류는 `aria-describedby`로 필드에 연결, 상태 변경 Toast는 `aria-live="polite"`, 오류 요약은 `role="alert"`. |
| 건너뛰기 | Header 앞에 "본문으로 건너뛰기" 링크 |
| 모션 | Drawer 열림 200ms 슬라이드. `prefers-reduced-motion`이면 페이드만 사용 |
| 색 대비 | 텍스트 4.5:1 이상, 아이콘·테두리 3:1 이상 (§3.1·§3.2 값) |

### 4.3 기본 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| **Button** | Primary: `coral-600` 배경 + 흰 글자, hover `coral-700`. Secondary: 흰 배경 + 1px `ink` 테두리. Tertiary: 텍스트 + hover 밑줄. Disabled: `#F2F2F2` 배경 + `muted` 글자 + `aria-disabled`. 외부로 나가는 버튼은 라벨 끝에 "새 탭" 아이콘과 숨김 텍스트 "(새 탭에서 열림)" |
| **Chip** | 높이 44px pill. 기본 흰 배경 + `hairline` 테두리, 선택 시 `coral-50` 배경 + `coral-500` 테두리 + 체크 아이콘 + `aria-pressed="true"`. 링크 Chip은 오른쪽 화살표 아이콘 |
| **Destination Card** | 4:3 사진(모서리 14px) → 여행지명(`title-sm`) → 국가·지역 → 테마 2개(`caption`). 사진 오른쪽 위에 즐겨찾기 아이콘 버튼(44px 원형, 흰 배경). Card 전체가 상세 Drawer를 여는 버튼 |
| **Safety Card** | 사진 없음. 국가명(`title-sm`) → 경보 단계 배지(semantic) → 한 줄 요약 → "최종 확인 2026.10.01" → stale이면 `warning` 배지 "재확인 권장". 흰 배경 + `hairline` 테두리 |
| **Mate Card** | 사진 없음. 상태 배지(모집중/마감) → 제목 → 국가·지역 · 기간 · 모집 인원 → 여행 스타일 Chip(읽기 전용) → 작성자 닉네임·연령대 |
| **Stat Tile** | 큰 수치(`stat`) + 라벨(`body-sm`) + 한 줄 설명. 테두리 없이 `surface-soft` 배경 |
| **Step Guide** | 번호 원(32px, `ink` 테두리) + 제목 + 1문장. Desktop 3열 가로, Mobile 세로 |
| **CTA Banner** | `surface-soft` 배경 둥근 상자(14px), 왼쪽 제목·설명, 오른쪽 버튼 1~2개. Mobile에서는 버튼이 아래로 내려가고 전체 폭 |
| **Alert** | semantic 배경·테두리 + 아이콘 + 제목(굵게) + 설명. 닫기 버튼 없음(고지·경고는 계속 보인다) |
| **Badge** | 높이 24px pill, `caption`, semantic 색 + 아이콘 |
| **Tabs** | 텍스트 탭 + 활성 2px `ink` 밑줄. `role="tablist"`, 높이 48px. Mobile에서 넘치면 가로 스크롤 |
| **Form Field** | 라벨(위, `caption` 굵게) → 입력(48px, `border-input`, 포커스 시 2px `ink`) → 도움말(`body-sm`, `muted`) → 오류(`danger` 아이콘 + 문장). 필수 항목은 라벨 뒤 "(필수)" 텍스트 |
| **Drawer** | 헤더(제목 + 공유 + 닫기 44px) 고정, 본문 스크롤. URL query와 연결되어 뒤로 가기로 닫힌다 |
| **Modal** | 최대 폭 560px, 정책 문서·신고·확인 대화상자에 사용. 브라우저 기본 `alert`/`confirm`은 쓰지 않는다 |
| **Toast** | 화면 아래 가운데(Mobile은 하단 전체 폭), 4초 후 사라짐, 작업 결과 1문장 |
| **Empty State** | 아이콘 + 제목 + 이유와 이용 방법 1~2문장 + Primary CTA + Secondary CTA |
| **Skeleton** | 실제 Card와 같은 크기의 회색 블록(`#F2F2F2`). 300ms 안에 응답하면 표시하지 않는다 |
| **Image** | 모든 이미지에 장소를 설명하는 `alt`. 로드 실패 시 `surface-soft` 배경 + 장소명 텍스트 플레이스홀더. 크기를 미리 고정해 레이아웃 이동을 막는다 |

## 5. Section 배치 공통 규칙

| 규칙 | 적용 |
|---|---|
| 순서 | Header → Section 1(Hero 또는 Intro) → Section 2… → Footer |

### 6.5 SCR-005 `/account` 계정·관리

**사용자 목표:** 로그인과 성인 확인을 마치고 내 글·요청·차단을 관리한다. 관리자는 신고 상태와 외부 이동 주소를 관리한다.

#### 역할별 탭

| 역할 | 렌더링하는 탭 (`?tab=`) | 기본 탭 |
|---|---|---|
| Guest | 로그인(`login`) — 탭 바 없이 단일 화면 | `login` |
| Member | 프로필(`profile`), 내 활동(`activity`) | `activity` (성인 확인 전이면 `profile`) |

## 8. 콘텐츠·이미지 규칙

| 항목 | 규칙 |
|---|---|
| 문장 | 제목과 설명은 존댓말 완성 문장으로 쓴다. 설명은 1~3문장. 버튼은 동사로 끝낸다("보기", "정리하기", "보내기") |
| 표현 | "인기 순위"처럼 객관적 순위를 주장하지 않고 "free_traveler가 고른"으로 쓴다 (PRD 3-3). 예약·가격·검색 결과를 제공하는 듯한 표현("최저가", "예약하기")을 쓰지 않는다 |
| 대표 수치 | 모든 화면에서 `50+ Trips`, `30+ Countries` 표기를 그대로 쓴다 |
| 이미지 | 일반 인터넷 이미지 URL + 실제 장소를 설명하는 `alt`. "사진", "이미지" 같은 단어로 `alt`를 시작하지 않는다. 장식용 아이콘은 `alt=""` |
| 인물 | 얼굴이 식별되는 인물 사진이나 특정 서비스를 보증하는 듯한 사진을 쓰지 않는다 (PRD 6-4) |
| 사진 비율 | Destination Card 4:3, 상세 Drawer 16:9, Hero·대표 사진 4:5, Gallery 1:1 또는 4:3 혼합 |
| stale 문구 | 안전정보 stale 경고는 SRS 문구 "최신 정보 재확인 필요"를 쓰고, Card에서는 "재확인 권장" 배지로 줄인다 |
